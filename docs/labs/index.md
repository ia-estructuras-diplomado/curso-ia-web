!!! tip "Un notebook de referencia por lab (Labs 0–4)"
    Cada notebook está completo y se ejecuta de punta a punta. Ejecútalo
    (Run All) para ver el resultado esperado y luego construye **tu propio
    notebook** guiándote por el README del lab y tu asistente de IA.
    Entrega tu notebook + `prompts_entregados.md`.

    Sin notebook: son guías paso a paso con **Claude Code** conectado por

    **Windows nativo con ETABS 21+**.

## Cómo empezar

1. [Instala el entorno](instalacion.md) (una sola vez).
2. Abre el notebook del lab con el intérprete `labs/.venv`.
3. Completa `prompts_entregados.md` en la carpeta del lab.
